## Learning Philosophy

> Learn → Understand → Apply → Document

The goal is not to memorize architectures or technologies.

I want to understand:

- Why a system needs a particular component
- How systems scale
- Where bottlenecks occur
- How failures are handled
- What trade-offs different architectures make
- How these concepts apply to real-world systems
